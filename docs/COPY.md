# Words

Short, plain, warm. A title and one line. Sentence case. No exclamation marks, no "Oops", no "Awesome".

| Use | Never |
|---|---|
| **Expense**, **Income**, **Transfer** | debit / credit in the UI (only "Money out" / "Money in" in rules) |
| **Bill** (anything that repeats); a **Subscription** is a kind of bill | recurring, scheduled transaction |
| **Paid**, **Skip** / "Skipped" | missed, failed, late |
| "Was due 17 Oct" · "Electricity is overdue" (notes only) | defaulted |
| "₹1,300 over" | exceeded, blown, overspent |
| **To review** (payments the app found) | pending, inbox, detected |
| **Account** (bank, cash, wallet, card, loan, savings) | wallet as the umbrella word |
| **Goal**, "Add money" | contribute, contribution |
| **Budget**, "left" | remaining balance |
| **Message rules**, "Teach a message" | parser, regex, template |
| "messages not understood" | unparsed, failed to parse |

Tabs: **Today · Activity · Plan · Insights · More**. Main buttons: "Add expense" (FAB), "Save",
"Mark paid", "Pay bill", "Add money", "Add rule".

Numbers: "₹13,644 left", "₹1,050 a day", "in 6 days", "Tomorrow", "Today", "42 of 240 EMIs paid".
Amounts are never coloured: expense "−₹450", income "+₹1,20,000", transfer "₹8,120" (no sign).
