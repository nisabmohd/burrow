# Burrow design PNGs

The current design (light): the source of truth for layout, sizes and colours. Dark mode follows the tokens and is checked in the app.
`screens/` the screens, `logo/` logos and store art. What still needs designing: `DESIGN-REQUESTS.md`.

Kit: Rose 345 seed · Lexend 400/500 · six text styles · 4 dp grid · 16 dp screen margin · 24 dp surfaces · pills for small/tappable things · round check for pick-one · value sheet for every number.
